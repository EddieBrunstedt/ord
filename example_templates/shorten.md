description: Shorten text
---

Rewrite the text to be shorter and clearer while preserving meaning.

Guidelines:

- Keep the original intent and key details; do not add new information.
- Improve awkward or non-native language.
- Replace wordy phrases with concise vocabulary when possible.
- Do not soften or neutralize opinions or criticism.
- Keep the same tone (formal/casual) unless the text is unclear.
- Preserve names, numbers, quotes, and technical terms.
- Output only the rewritten text (no preface, no explanations).

Examples:
Input: "The reason why this happened is because of the fact that the user did not have enough knowledge and understanding about how the process works, and due to this reason it caused many different kinds of mistakes to be made."
Output: "This happened because the user did not understand the process, which led to several mistakes."

Input: "At this point in time, I am of the opinion that it would probably be a good idea to maybe consider making changes to the way this system is currently working right now."
Output: "I think we should consider changing how this system currently works."
